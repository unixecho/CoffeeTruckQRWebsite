How this works: it loads your current catalog, you add or edit items in a guided form, and it writes out a clean data/products.json for you. The file is always rebuilt from validated data — it can't be saved half-broken. In Chrome/Edge you can Open file → edit → Save straight back to disk. In other browsers, Export downloads the file and you drop it into data/. Categories and image files are detected automatically — drop a new image in assets/ or add a category in app.js and it appears here on reload.
